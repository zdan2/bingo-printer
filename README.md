# ビンゴ抽選＋サーマル印刷

タブレット（iPad / Android）のブラウザで番号を抽選し、ESC/POS 対応のサーマルプリンターで番号を大きく印刷する。

## 本番構成: ラズパイ1台＋USBプリンター

```
タブレット ──Wi-Fi「BINGO」──▶ ラズパイ (Wi-Fi親機＋server.py) ──USB──▶ サーマルプリンター
```

会場に持ち込むのはラズパイとプリンターだけ。会場の Wi-Fi やルーターは使わない。

### 初期設定（1回だけ。自宅のネット環境で行う）

1. Raspberry Pi OS（Bookworm）を入れたラズパイに、このフォルダをコピーする。
   ```bash
   scp -r C:/test/bingo-printer <ユーザー名>@<ラズパイのIP>:~/
   ```
2. プリンターを USB でつなぎ、電源を入れてから認識を確認する。`/dev/usb/lp0` が出ればよい。
   ```bash
   ls /dev/usb/
   ```
3. セットアップを実行する（パスワードは Wi-Fi「BINGO」用。8文字以上）。
   ```bash
   cd ~/bingo-printer && chmod +x setup_pi.sh && sudo ./setup_pi.sh <パスワード>
   ```
   SSID や帯域を変えるときは `sudo ./setup_pi.sh <パスワード> BINGO a`（`a` は 5GHz。Pi 3B+/4/5 のみ。既定 `bg` は 2.4GHz）。
4. `sudo reboot` で Wi-Fi 親機に切り替わる。この時点で自宅 Wi-Fi・Tailscale からは切れる。

### 当日

1. プリンター → ラズパイの順に電源を入れる（1分ほどで Wi-Fi「BINGO」が出る）。
2. タブレットを Wi-Fi「BINGO」につなぎ、`http://192.168.50.1/` を開く。
   - Android で「インターネットに接続されていません。接続を維持しますか」と出たら「はい」。
   - iPad は Safari の共有 →「ホーム画面に追加」、Android は Chrome の「ホーム画面に追加」で全画面になる。
3. 画面左上が「プリンター接続OK」（緑）なら準備完了。

### 保守

- ラズパイに入る: Wi-Fi「BINGO」につないで `ssh <ユーザー名>@192.168.50.1`
- サーバーのログ: `journalctl -u bingo -f`
- 自宅 Wi-Fi に戻す: `sudo nmcli con mod bingo-ap connection.autoconnect no && sudo reboot`
- 電源の抜き差しで SD カードが壊れないよう、動作確認が済んだら読み取り専用にしておく: `sudo raspi-config nonint do_overlayfs 0 && sudo reboot`
  （設定を変えるときは `do_overlayfs 1` で解除して再起動）

## 2台で使う（保護者席・カメラ席）

席ごとに別々のビンゴとして進む。番号も履歴も別。プリンターは1台を共用する。

| 席 | URL | 画面の色 | 紙の印字 |
|---|---|---|---|
| 保護者席 | `http://192.168.50.1/parent` | オレンジ | 「保護者席」＋番号 |
| カメラ席 | `http://192.168.50.1/camera` | 青 | 「カメラ席」＋番号 |

- `http://192.168.50.1/` を開くと席を選ぶ画面が出る。選んだ席の画面を「ホーム画面に追加」しておくと、次からその席で開く。
- 席名と番号は、ラズパイが IPA ゴシックで画像にして印字する（ラスター印字）。1〜99 の画像は起動後 10 秒ほどで裏で作り終わる。
  Pillow かフォントがない環境では、プリンター内蔵フォントで英字（`PARENTS` / `CAMERA`）＋番号を印字する。

### 実機（LOUJIN 80mm）で分かったこと

- 券ごとに ESC @（初期化）を送ると、前の券の印字中に届いたとき未印字分が消えて途中で切れる。そのため送らない。
- 紙送り命令（ESC d）は、次の券が続けて届くと効かないことがある。下余白は画像の白い行として入れている。
- 内蔵の漢字フォントは中国語用（GBK）。Shift_JIS は文字化けする。

## 使い方

- 「次の番号」をタップ → 即座に表示、裏で印刷。印刷の完了は待たない。
- Bluetooth キーボードやプレゼン用リモコンのスペース / Enter / → / PageDown でも抽選できる。
- 右側の盤面で出た番号を確認できる（オレンジが直前の番号）。
- 印刷に失敗した番号は赤帯に「未印刷」として残るので、プリンター復旧後に「まとめて再印刷」。
- 抽選状態はタブレットのブラウザに保存されるので、リロードや画面ロックでは消えない。最初からやり直すときは 設定 → リセット。
- 範囲は 設定 から変更する（既定 1〜75）。

## server.py のオプション

```bash
python3 server.py --usb /dev/usb/lp0      # USB 接続
python3 server.py --printer 192.168.1.50  # LAN 接続 (TCP 9100)
```

| オプション | 既定 | 内容 |
|---|---|---|
| `--paper 58` | 80 | 58mm 用紙のとき指定（文字倍率が自動で収まる大きさになる） |
| `--no-cut` | カットする | オートカッターがない／切りたくないとき |
| `--feed N` | 4 | 券の下余白（行数。画像印字では 1行 = 30 dots の白い行） |
| `--text-mode` | 画像印字 | 画像を使わず内蔵フォントで印字する |
| `--font PATH` | IPA ゴシック | 画像印字に使うフォント |
| `--http-port N` | 8080 | 画面配信ポート（ラズパイのサービスは 80） |

ラズパイで設定を変えるときは `/etc/systemd/system/bingo.service` の `ExecStart` 行を書き換えて `sudo systemctl daemon-reload && sudo systemctl restart bingo`。

## 本番前の練習（プリンターなし・Windows）

```bash
python fake_printer.py
```

別ウィンドウで

```bash
python server.py --printer 127.0.0.1
```

ブラウザで `http://127.0.0.1:8080/` を開く。疑似プリンターのウィンドウに印刷された番号が表示される。
